# PRODUCT

## Product

Dashboard Calendar Event is an event operations and public marketing system for Metropolitan Mall Bekasi. It combines a public community landing page, public event schedule/gallery experiences, survey pages, and an admin dashboard for managing mall events.

## Register

brand

The public landing page is a marketing/campaign surface. Design is part of the product: it must persuade communities, schools, companies, organizers, and institutions to collaborate with Metropolitan Mall Bekasi.

The dashboard/admin surfaces are product UI. Design serves speed, clarity, data quality, and operational confidence.

## Primary Users

- Community leaders looking for venue, equipment, promotion, or sponsorship support.
- Schools, universities, campus organizations, companies, event organizers, NGOs, and government teams proposing events.
- Mall marketing/admin staff managing event schedules, registrations, galleries, surveys, and approvals.
- Public visitors browsing upcoming events and gallery content.

## Core Promise

Bring communities to Metropolitan Mall Bekasi with practical support: venue, sound system, lighting, promotion, and collaboration opportunities, subject to concept review and schedule availability.

## Product Goals

- Convert qualified organizations into event collaboration registrations.
- Make upcoming mall events easy to discover and understand.
- Help admin users manage event operations with fewer manual steps.
- Present Metropolitan Mall Bekasi as active, welcoming, organized, and community-friendly.

## Landing Page Message

Main idea: Metropolitan Mall Bekasi supports community events with free venue facilities and production support.

Recommended message:

> Bawa komunitasmu tampil di Metropolitan Mall Bekasi — venue, sound, lighting, dan promosi dibantu tanpa biaya.

Important qualifiers:

- Registrations are reviewed by the mall team.
- Availability depends on schedule, concept, and operational fit.
- Facilities depend on event needs and approval.

## Tone

Use confident Indonesian with selective English only when it is familiar event language.

Preferred tone:

- energetic but credible
- warm but not childish
- clear and direct
- community-first
- institutionally trustworthy

Use:

- "Daftar Kolaborasi"
- "Fasilitas"
- "Cara Daftar"
- "Tim kami akan menghubungi PIC dalam 3-5 hari kerja"
- "Sesuai kurasi dan ketersediaan jadwal"

Avoid overusing:

- mixed English/Indonesian in one label
- excessive slang for formal users
- vague claims without context
- generic SaaS wording

## Strategic Principles

1. Conversion first: every section should move users toward registration or event discovery.
2. Proof before form: show real events, gallery, stats, and facilities before asking users to submit.
3. Trust through clarity: make free/support claims clear with process and conditions.
4. Accessible by default: keyboard, screen reader, reduced motion, contrast, and labels are non-negotiable.
5. Operational accuracy: copy must match what mall team can actually provide.
6. Mobile-first: many visitors arrive from Instagram or WhatsApp on mobile.
7. Reusable craft: shared landing primitives should keep campaign pages consistent.

## Anti-References

Avoid designs that feel like:

- generic AI SaaS landing pages
- over-polished tech startup pages unrelated to malls/events
- cluttered event posters with too many competing CTAs
- admin dashboards disguised as marketing pages
- flashy motion that hurts readability or mobile performance

## Main User Journeys

### Community Registration

1. User lands on `/`.
2. User understands free venue/support offer.
3. User reviews benefits, facilities, steps, proof/gallery/events.
4. User fills registration form.
5. User receives success state and follows Instagram or waits for follow-up.

### Event Discovery

1. User lands from public link/social.
2. User browses upcoming or featured event.
3. User opens event detail or gallery.
4. User may continue to dashboard/event schedule.

### Admin Operations

1. Admin logs in.
2. Admin manages dashboard event data, drafts, registrations, gallery, survey, and event views.
3. Admin keeps public schedule reliable and current.

## Success Signals

- Higher completed community registrations.
- Fewer confused or incomplete form submissions.
- Users can reach registration quickly from mobile.
- Admin users can manage event content without breaking public presentation.
- Build, accessibility, and visual QA stay clean after changes.
