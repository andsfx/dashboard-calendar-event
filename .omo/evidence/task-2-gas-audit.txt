# T2: GAS Audit Findings

GAS is NOT safe to remove.

Active dependency found:
- `src/App.tsx` uses `createLetterRequest`.
- `src/utils/supabaseApi.ts` implements `createLetterRequest` by POSTing to `/api/apps-script-admin`.
- `api/apps-script-admin.js` forwards that request to Google Apps Script using `APPS_SCRIPT_URL` + `ADMIN_API_TOKEN`.
- `google-apps-script.js` contains actual GAS `createLetterRequest` handler.

Letter request feature has no Supabase alternative found. Search for `letter|surat` found no Supabase endpoints replacing it.

Therefore, `api/apps-script-admin.js`, `APPS_SCRIPT_URL`, and `ADMIN_API_TOKEN` MUST REMAIN.
`api/apps-script-public.js` and `src/utils/sheetsApi.ts` appear unused and could be removed, but the core GAS integration is still active.

Decision: T5 (Remove legacy GAS) will be skipped or modified to only remove `apps-script-public.js` and `sheetsApi.ts`.
