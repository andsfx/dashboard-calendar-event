# Test Reports

This directory contains test reports generated by various testing tools.

## Directory Structure

```
reports/
├── playwright/        # Playwright E2E test reports
│   ├── index.html    # Main report
│   └── results.json  # JSON results
├── coverage/         # Code coverage reports
│   ├── index.html    # Coverage report
│   └── lcov.info     # LCOV format
├── k6-summary.json   # k6 load test JSON results
└── k6-summary.html   # k6 load test HTML report
```

## Viewing Reports

### Playwright Reports

```bash
npx playwright show-report reports/playwright
```

Or open `reports/playwright/index.html` in a browser.

### Coverage Reports

```bash
open reports/coverage/index.html
```

### k6 Load Test Reports

```bash
open reports/k6-summary.html
```

## Report Retention

Reports are generated locally and not committed to git (see `.gitignore`).

In CI/CD, reports are uploaded as artifacts for review.

## Generating Reports

Reports are automatically generated when running tests:

```bash
# Generate E2E report
npm run test:e2e

# Generate coverage report
npm run test:coverage

# Generate load test report
npm run test:load
```
