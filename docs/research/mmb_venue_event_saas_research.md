## Most relevant to MMB — top 5 patterns to copy (not necessarily buy)
1. **Skedda** — the space-entity pattern: make "location" a first-class space object with per-space calendar, capacity, booking rules and conflict prevention; directly fixes MMB's free-text location + no double-booking gap.
2. **Pickspace (Marketing Space Manager)** — mall-native answer to MMB's space-booking hole: bookable inventory of event spaces/kiosks/signage with calendars, pricing and contracts — adds a revenue/monetization angle to the ops dashboard.
3. **Booking Ninjas** — closest full analogue to MMB's dashboard: mall events + promotions module plus a booking engine that "prevents scheduling conflicts," with tenant portal, foot-traffic and tenant-performance analytics (mirrors MMB's sales_lift/traffic_lift surveys) and approval routing.
4. **Eventbrite (organizer)** — the pattern for maturing MMB's public event pages + registration form: self-service publish, RSVP/ticket types, check-in, per-event analytics; free for free events so it's the zero-cost benchmark.
5. **Momentus (Booking Bundle)** — the booking-lifecycle pattern: availability → holds → proposal/contract → approval → billing, explicitly marketed to "stop double booking"; its Self-Service and Registration bundles show how approval workflows and public registration should integrate with a venue calendar.

**Also worth watching:** Luma's approval/token-gated registration is the cheapest way to add an approval workflow for community/tenant submissions; OpenActive shows how publishing events as open data feeds discovery (mall website + Google + partner apps); Placewise covers the shopper-CRM/loyalty layer above the ops dashboard (bigger scope than event ops).
